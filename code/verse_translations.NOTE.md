`verse_translations.py` is not distributed: it held English translations by Swami Mukundananda and
A. C. Bhaktivedanta Swami Prabhupada, which are under copyright. Supply your own file with the structure
`VERSE_TRANSLATIONS = {"BG 2.1": ["translation 1", ...], ...}` for all 72 verses to run the alpha > 0
meaning profiles. The alpha = 0 (translation-free) results in the paper do not need it.
